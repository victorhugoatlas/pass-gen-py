# PassGen | v0.4
Um gerador de senhas simples, leve e seguro desenvolvido em Python utilizando Tkinter. É possível alterar o comprimento da senha, incluir caracteres especiais, definir um nome de usuário e salvar tudo diretamente em um arquivo de texto no Desktop.

## Funcionalidades
* **Geração Personalizada:** Escolha o tamanho da senha de 1 a 30 caracteres.
* **Opção de Símbolos:** Possibilidade de incluir caracteres especiais (`@#$Çç!?`).
* **Identificação de Usuário:** Campo opcional para associar a senha a um usuário.
* **Salvamento Automático:** Exporta a senha e o usuário de forma organizada direto para um arquivo `.txt` na sua Área de Trabalho.

## Tecnologias Utilizadas
* **Python 3**
* **Tkinter**

## Como Executar
1. Certifique-se de ter o Python instalado na sua máquina.
2. Clone este repositório ou baixe o arquivo `main.py`.
3. Abra o terminal na pasta do projeto e execute:

```bash
python pass-gen.py
